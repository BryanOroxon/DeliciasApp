# DeliciasApp
# 🌮 .NET MAUI DeliciasApp

**DeliciasApp** es una aplicación multiplataforma desarrollada con **.NET MAUI** como parte del evento **Bryan’s Summer Party** en **Cholula, Puebla**. Su propósito es resaltar la riqueza gastronómica de la región poblana con las delicias más representativas de la cocina poblana.

📆 Evento: *28 de junio de 2025*  
📍 Lugar: *Cholula, Puebla, México*

---

## ✨ Funcionalidades

- Interfaz nativa con **.NET MAUI** y **XAML**
- Navegación sencilla y visualmente atractiva
- Soporte **multiplataforma**: Android, iOS, Windows
- Lista de platillos típicos con imágenes

---

## 🛠️ Tecnologías utilizadas

- 💻 C#  
- 📦 .NET 9  
- 📱 .NET MAUI  
- 🖌️ XAML  
- ⚙️ Visual Studio 2022+
